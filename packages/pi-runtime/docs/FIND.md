# Saved-conversation Find

The [portable contract](../../contracts/docs/TRANSCRIPTS.md#complete-conversation-find) owns requests, exact original-text ranges, simple Unicode folding and reply bounds. `Host.findTranscript` reauthorizes exact host/store/actor/conversation metadata before each slice; `find.ts` reads public ascending `scanEntries` with inclusive lower/upper IDs and advances past completed rows without duplicate boundaries. A committed upper cutoff and MAC-bound start/continuation cursors make replay independent of later appends. The existing authenticated command RPC and desktop command bridge carry the operation; there is no extra endpoint, IPC channel, polling, execution store, index or scheduler.

`transcript.ts` shares one private message-value policy between descriptors/content and Find. Search skips unavailable/redacted/image values, does not decode image bytes, and does not build or hash a whole entry's part array. The authenticated private cursor carries the next message, content block and auxiliary slot (argument error, nested calls, details, patch/diff or safe failure notice), so a continuation never enumerates preceding messages or constructs preceding parts. Empty messages consume the same independent position budget. Compact JSON uses bounded scalar-string fragments and seekable numeric token paths, so continuation can resume inside one large JSON value without serializing its previous values again. Property keys, escaping, array/object punctuation, CRLF and surrogate pairs preserve the existing JSON.stringify display interpretation. Saved SDK JSON values are plain JSON; private task checkpoints are not searched. Requested/executed arguments remain distinct according to the existing retained-display policy; the SDK does not retain every execution-time argument in saved entries.

After an initial one-row cutoff capture, a page returns at most 32 matches and examines at most 32 rows, processes at most 32 part/message positions and consumes at most 256 KiB new text. The generator may construct one additional lookahead position; it never reconstructs an already-consumed prefix. Each CPU window is at most 16 Ki UTF16 plus bounded query/snippet lookahead. The loop yields between bounded windows/parts and every 32 JSON tokens, checks cancellation around SDK calls and resumes at its next unconsumed position. It bounds actual serialized JSON against the existing 256 KiB transport limit. An overlong authenticated cursor fails explicitly rather than clipping the conversation. No-match requires terminal completion, including an empty conversation.

These are delivery/processing/retention bounds, not a hard SDK heap or wall-time bound. Public Pi reads necessarily allocate one complete SDK EntryRecord. Inspecting an invalid Unicode string and enumerating one JSON object's keys still use that SDK value; large allocation/native validation cannot be preempted midway. Deep JSON beyond a usable cursor/JS stack fails safely. Neither Find nor content reads recover omitted tool output or retired live checkpoints. Replaying an evicted result trades another bounded scan for retaining an unbounded index.

`Host.read` signals interruption while keeping actual Promise settlement in root work. `Host.run` leaves Find interruptible and outside Send's semaphore. The network server passes its peer-close AbortSignal through the existing client call; remote response proofs, connection generations and schema/echo/range validation remain intact. Harness release waits for held SDK work even after the caller has received Cancelled. Reads never Send/retry/Stop.

## Tests

`test/find.test.ts` covers 1,100 mixed records, 2 MB split JSON, original Unicode/chunk ranges, images/signatures/redaction exclusion, dense pages, fixed cutoff/replay, wrong query/authority/tamper/restart and held SDK cancellation/Stop/disposal. `test/find-work.test.ts` instruments SDK reads, including indexed access, so a continuation that reconstructs preceding blocks fails regardless of iteration syntax; it also bounds empty-message traversal and checks exact message/argument-error/nested-call/details/patch/diff ranges. The Find case in `test/transport.test.ts` covers the authenticated loopback handler, replay and peer cancellation. Build/native/package, broad process integration, real provider/SSH, physical performance and manual accessibility are outside these controlled source tests.
