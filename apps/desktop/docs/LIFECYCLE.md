# Desktop model and document ownership

Main acquires workspace and optional remote-chat/SSH capabilities once. Each trusted document owns an Effect child scope under that runtime; each bounded IPC request/watch owns a child scope. The existing cancellation channels use invoke/handle and return a validated `Reply<null>` only after local wait/watch finalizers settle. Cancellation never acknowledges mutation rollback or remote task termination. Repeated close joins the retained outcome; document replacement immediately fences delivery/authority before draining old scopes. Successful native captures install their privileged release finalizer in the captured document scope before references are published. Late capture, picker and command completion cannot grant authority to the replacement document. Claimed native descriptors remain workspace-owned.

Each live renderer creates one empty runtime and aggregate scope. It acquires each public editor/chat model in a removable child acquisition scope, then binds facades to those exact instances. Panel cleanup releases both the model and its acquisition scope, even on failure, so repeated reopening does not retain retired models until Quit. Models install no backend capability. Edits, chat preservation and editor recovery readiness remain synchronous unload gates. The main process independently releases document resources after committed navigation or process loss; renderer unload cleanup is best effort.

View switching keeps the editor mounted and detaches/resumes chat observation. **Close Chat panel** first preserves its saved work, synchronously fences model admissions, removes its UI, and retains an Effect cleanup task in the renderer aggregate scope. The editor remains usable. **Open Chat panel** acquires a fresh model only after successful cleanup releases that namespace. Failed cleanup retains the namespace lease, appears in a bounded application-owned error area and remains part of Quit's cleanup result. No lifecycle action Stops remote work or automatically repeats Send.

Quit preserves chat, runs the editor's exact Save/Discard/Cancel gate, then preserves newer chat edits. A veto retains the live UI. After consent the renderer becomes inert, drains every closing task, releases aggregate scope/runtime and returns the matching disposal acknowledgment with an optional strictly validated bounded error DTO. Main attempts all its releases and reports failures natively before exit. A failed cleanup does not restore a disposed UI. Forced document/process loss is not a physical durability guarantee.

Public contracts remain in `packages/application`; desktop adds only private IPC/native/disposal envelopes, raw size/depth bounds and document authority. Recovery replies use the strict saved-data decoder, so unfamiliar nested fields cannot be projected away and republished. The private configuration reader retains owner/no-follow/16 KiB/strict-field/actor/32-character-minimum rules while consuming the SSH decoder's privileged profile and executable policy.

Source tests hold/fail actual IO observation finalizers. Native fault tests hold cancellation delivery and inject a safe cancellation acknowledgment failure through the test-only entry, then verify the real renderer's removal, namespace gate, visible error and Quit drain. They do not claim an injected acknowledgment is a real OS release failure. The shipped package excludes all such hooks; packaged tests exercise its normal close/reopen and lifecycle paths. Real SSH/providers, OS gestures, VoiceOver, physical durability, Intel and distribution remain separate qualification.
